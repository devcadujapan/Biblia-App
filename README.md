# 📖 Bíblia App - ACF

[![Licença MIT](https://img.shields.io/badge/Licen%C3%A7a-MIT-blue.svg)](LICENSE)
[![React Native](https://img.shields.io/badge/React%20Native-0.83-61DAFB?logo=react)](https://reactnative.dev/)
[![Expo](https://img.shields.io/badge/Expo-55.0.25-000020?logo=expo)](https://expo.dev/)

Aplicativo de leitura da Bíblia Sagrada na versão **Almeida Corrigida Fiel (ACF)**. Desenvolvido com React Native e Expo, com suporte para web.

![Preview](https://via.placeholder.com/800x400?text=App+da+Bíblia+ACF)

## ✨ Funcionalidades

- 📚 **66 livros** da Bíblia completa
- 📖 Navegação por **livro → capítulo → versículo**
- ✅ **Marcar capítulos** como lidos com checkbox
- 🌓 **Tema claro/escuro** (persistente)
- 👤 **Perfil do usuário** com nome personalizado
- 💾 **Progresso de leitura** salvo automaticamente
- 📱 **Responsivo** - funciona em desktop e dispositivos móveis
- 🚀 **Performance otimizada** com carregamento rápido
